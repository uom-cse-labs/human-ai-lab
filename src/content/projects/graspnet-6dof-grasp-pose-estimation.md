Grasping objects in complex and cluttered environments remains a challenging problem for robotic systems, as it requires accurately understanding object geometry and determining suitable grasp positions. This project explores 6-DoF grasp pose estimation using visual data to identify the optimal position and orientation for robotic grasping.

The research utilizes the GraspNet-1Billion benchmark, a large-scale dataset containing diverse objects and annotated grasp poses, to train and evaluate deep learning models. Different approaches for 3D point cloud processing, feature extraction, and grasp quality prediction are investigated to improve grasp detection accuracy and robustness.

The models are evaluated using the standard GraspNet API, allowing comparison with existing research methods. The ultimate goal is to contribute toward more reliable robotic perception systems capable of performing accurate object manipulation in real-world environments.
